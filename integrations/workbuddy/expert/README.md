# 见微 · 产品机会研究专家 0.1.0

从模糊想法澄清，到资料取证、反证审查及最小验证计划。可读取已有研究进行逐项核查。
这是 WorkBuddy 原生专家；已有网页版的数据库、开发者密钥、后台任务和预算功能不在本包内。

## 使用
导入本专家 ZIP，召唤“见微”，输入一个想法或提供授权研究正文。范围明确后执行研究；工具受平台实际分配约束。没有联网工具时仍可审查已有正文，不能把未读取页面当证据。
可执行环境中，专家使用 scripts/audit.py 检查引文精确定位、版本、完整分句覆盖和报告状态。该脚本不会验证事实真假或保证模型准确。
只把 ZIP 内容直接打到根目录，保留 .codebuddy-plugin/plugin.json；不要上传整个代码仓库 ZIP。

## 示例
- 我想帮小团队整理客户反馈，先帮我明确目标用户和决策问题。
- 审查我提供的三份资料，区分真实依据、反证和未知。
- 我已有研究结论，请设计两周内可完成的最小验证。

## 数据与费用
专家不连接作者数据库，不收集遥测，也不自带外部模型密钥。用户输入、公开检索及模型处理由 WorkBuddy 和实际工具提供方处理；本包不能保证数据永不离开设备。敏感资料先脱敏。
本地检查脚本仅处理指定文件，研究记录留在用户选择的工作区。删除该目录可删除本地交付物；平台会话请在平台管理。
平台模型、检索或连接器可能计费；本包不承诺免费额度或 token/费用准确计量。
