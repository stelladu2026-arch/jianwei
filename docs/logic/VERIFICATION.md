## 自动同步方式

GitHub workflow 在相关源码 push 后重新生成并写回代码提取文档，在 pull request 中只读检查。人工业务图过期会使最终检查失败，编码助手需核对内容后更新复核记录。自动生成不会清除这项待办。

首次云端运行状态以仓库 Actions 的实际结果为准。本地脚本通过、工作流文件已提交都不能代替云端执行成功；工作流写权限不足、并发更新或网络失败应作为未完成事项保留。
