# 研究工作台视觉与交互

## 组件与设计

复用项目已有 shadcn/ui Card、Button、Tabs；研究模式使用可键盘操作的分段选项卡，概览和开始操作复用既有组件。参考 beUI 的卡片与分段控件、Transitions 的状态过渡思路，以本项目 CSS 与 React 实现森林绿、浅暖色卡片与轻量反馈。

- 概览统计只计未归档项目、未排除的非虚构资料和有效待确认草稿；尚未载入时显示占位符。
- 项目卡增加悬停、聚焦、打开研究提示；原导航和按钮禁用原因保留。
- 研究进程按保存记录展示完成、当前、停止及未触发阶段。采集中的一批成功不等于整个采集阶段完成。
- 只有运行状态且租约有效时显示执行动效；过期或缺失租约显示“状态待确认”，不假装模型仍在运行。
- 工具活动按实际回执区分已执行与未执行，不把拒绝项展示成成功操作；原详细记录保留。
- 结论突出当前建议、下一步行动、反证和未知项，草稿、历史、演示及人工确认边界保留。
- 弹层与展开使用短过渡，窄屏重排，遵循系统减少动态效果设置。视觉切换不调用模型、不改变研究记录或预算。

官方参考：

- https://ui.shadcn.com/docs/components
- https://beui.dev/
- https://transitions.dev/

没有复制外部组件源码；本轮使用已有项目依赖，没有新增运行时远程脚本或外部动画依赖。

## 验证

新增 7 项 React 静态渲染检查，覆盖有效与过期执行租约、暂停/失败、未触发阶段、多批采集、工具拒绝分类和概览计数。原研究与恢复回归继续执行。浏览器布局、键盘和动效仍需人工验收，静态渲染不等于浏览器验收。
