# 中文资料入口与来源失败处理

## 本次代码变更

- V2EX 来源选择和对应研究记录旁提供“导入中文原文”入口，直接打开既有资料导入表单。
- “复核已有资料”仅切换至四角色模式，仍需操作者确认预算并点击开始。当前检查点、范围或正文不满足条件时禁用，不隐式发请求或追加重试。
- 手动导入支持匿名作者编号与讨论串／文档编号，复用已有服务端字段和同作者／同线程合并计数规则。未填写时仍按未知记录，不推断作者身份。
- 更新模型设置说明，准确描述 TypeScript、LangGraph.js、有界工具循环、四角色权限、自动待确认草稿与来源采样。

导入须确认使用授权，保留原文、来源和日期。公开讨论、自述支出与资料定位均不等同于实际交易核实或人群代表性。来源读取失败不自动切换接口、跟随跳转或重复请求；仍可用已有原文研究。
