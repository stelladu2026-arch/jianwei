# 研究工作台文案排版：四大设计原则

范围：一键研究、执行与评测，以及复用的阶段成果和结论摘要。

| 原则 | 实际调整 |
| --- | --- |
| 亲密性 | 选项说明紧贴控件；请求上限和开始按钮成组；异常原因与处理按钮在同一提示中；阶段成果将已获得、未完成、下一步分别成组；长技术说明可展开。 |
| 对齐 | 标题与正文左对齐；字段等宽网格；资源标签左对齐、数值右对齐；恢复列表使用统一操作列；窄屏按阅读顺序转成单列。 |
| 重复 | 统一正文、标题、辅助文案层级与 8/16/24/32 间距；两页共用提示组件；配置、确认、操作及明细使用一致样式。 |
| 对比 | 主标题 22px、正文 15px、控件与说明 14px、辅助文字 13px；当前建议 24–28px；深绿突出主操作，评测保留次级按钮；警告、错误有文字与边框区分，不仅依赖颜色。 |

段落改成短句，减少同一行承载多个主题。研究问题、判断、行动、反证及待验证内容分别标识，原文与历史依据仍可展开查看。

## 验证与边界

387 项既有离线检查、TypeScript、托管生产构建通过。对正文、辅助文案、警告、主按钮和中性标签的常态文字配色进行计算，所选组合对比度均超过 4.5:1，最低为 4.97:1；这不等于完整无障碍审计或浏览器验收。

浏览器实际换行、点击、键盘和具体屏幕布局仍待人工验收。本次没有真实模型或来源请求，没有更改预算、重试、权限、引用或历史数据约束。
