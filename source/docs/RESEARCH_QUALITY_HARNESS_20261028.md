# 研究质量与 Harness 同步优化

## 已实现
- 工作流报告统一使用 workflowModelUsage 的逐次回执统计，工具循环多次调用不再按阶段合并成一次；失败和未知用量保留。
- 当前范围与资料版本仍一致的已完成研究，界面展开与导出使用派生报告，不写回历史。过期资料和历史报告保持原文。
- evidence-boundary/1 用确定性特征提示开发任务、产品展示、背景统计与待人工核查资料；不自动确认用户身份、语义相关性、交易或独立客户数。全部间接线索时明确暂不足以确认目标痛点。
- 模型提示按目标动作和问题信号检索，要求区分资料与假设；没有直接依据时优先补证决策，提出包含对象、动作、指标及停止标准的计划。没有增加模型调用、自动补搜或重试。
- 结论摘要与导出报告增加证据用途及判断边界。模型原输出仍保留，不伪造已通过语义核查，也不自动修改历史机会卡。
- Harness 阶段快照保存模型、质量协议、初始资料用途提示；工具新增资料在每次模型输入重新生成用途提示。线程绑定纳入模型及协议，恢复时对不兼容/无版本旧快照拒绝继续。

## 验证
- 默认完整离线 API 回归通过，包含四项新增边界/回执测试。
- Harness 新增模型版本漂移、质量规则漂移、旧无版本快照拒绝恢复测试，确认无额外模型请求；相同版本正常恢复与已确认回执复用仍通过。
- 生产构建及 TypeScript 检查。真实模型调用：0。

## 实际边界
本轮未新增语义分类模型、语义正确性打分或自动判定目标角色匹配，不保证搜索渠道能覆盖实施顾问。来源类型提示有误判/漏判可能，需人工核查。提高提示约束不等于已实测模型一定遵守；需后续用户手动真实验收。旧线程不兼容时保留记录，按既有流程显式准备新阶段或新轮，不重置预算。
