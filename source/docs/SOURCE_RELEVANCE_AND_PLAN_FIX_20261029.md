# 资料用途与计划误报修复（2026-10-29）

针对用户提交的n8n时区草稿中，无关开发任务进入结论、镜像来源误作直接反馈、无依据替代建议及指标识别误报，完成以下变更。

- 共用sourceFit规则识别明显开发任务、交互原型、任务交付与资讯汇总；对n8n/Dify/Cloudflare/Discourse主题，其他GitHub仓库仅正文提及产品且标题不对应者暂不纳入需求分析。标题明确描述研究产品的第三方真实集成问题继续保留。仅为保守规则，不宣称语义相关性已验证。
- 采集、已有资料分析、四角色冻结、普通执行与工具输入都使用规则。历史原文不删除、不修改；页面列出暂未纳入资料及原因。规则可能误筛，需人工核对；无合格资料正常保留缺口。

- Mirror、镜像与转载单列用途，提示回溯原始来源、版本、复现与修复状态。没有新增自动回溯网络请求，也没有将镜像技术陈述升级为已核实事实。
- 提示词明确不受同一缺陷影响不等于职责等价或可替代；无官方资料不能断言功能缺失。阅读版与结论摘要增加可见规则提示，缺少官方能力依据、未经核查替代方案和镜像引用均明确说明。规则提示不改写历史模型输出，也不证明新输出语义正确。
