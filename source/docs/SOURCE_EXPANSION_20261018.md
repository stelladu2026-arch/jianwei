# 多来源采集与分析（2026-10-18）

## 已实现

| 渠道 | 获取内容 | 边界 |
| --- | --- | --- |
| 少数派 | 近期订阅摘要；剩余请求内回源匹配文章正文 | 非全站历史检索；未取得全文保留摘要标记；不解锁付费内容 |
| 博客园 | Atom 订阅；剩余请求内读取文章正文区域 | 只采近期匹配条目；不抓导航、脚本、评论和任意外链 |
| OSCHINA | 官方新闻订阅摘要 | 不把摘要或资讯当客户需求；当前新闻页为应用壳，未宣称取得完整正文 |
| GitHub Issues | 公开问题搜索及正文 | 不含全部评论、私有仓库或真实购买验证；保留搜索不完整标记 |
| Hacker News | 搜索、帖子与有限一级评论 | 固定请求分配下优先一帖及一条评论；无正文的帖子不进入分析 |
| 中文维基百科 | 搜索与有限条目摘录 | 只作背景，不当作国内用户需求原话 |
| V2EX | 原有中文节点订阅入口继续保留 | 仍是节点近期主题采样，不是全站搜索 |

一键研究的“多渠道公开检索”和证据库的手动采集共用新采集器。新模型工具 public_source_search 可以返回同一批来源；旧单站工具不会跳过后续的多渠道采集。默认来源、模型次数、单阶段模型次数及本轮来源上限均未提升：每个采集词或工具最多 10 次来源请求，自动研究最多 30 次来源请求，失败请求正常计数，不自动重试。

采集器并行处理固定来源，按渠道保留成功、未命中与失败回执。候选链接只允许官方文章主机及固定路径；拒绝重定向、凭据、私网地址、XML 外部实体和超大响应。公开原文被作为数据，不能改变工具权限。

每条新资料记录 contentBasis=full/excerpt。文章回源未完成时，摘要仍保留，页面与引用范围明确提示；不把零命中解释为没有需求，不把公开问题、文章或作者自述升级为付费事实。输入模型时按来源轮转，保留旧引用优先级；超出上下文的资料留在项目和回执中，显式提示未纳入本次输入，未向模型提供的编号不能引用。

中文规划已支持中文/英文短关键词；原先 ASCII 限制改为允许汉字，URL、异常字符、过长与重复检索仍拒绝。四角色首轮盲核查、CAS、租约、幂等、迟到结果和真实模型额度约束保留。
