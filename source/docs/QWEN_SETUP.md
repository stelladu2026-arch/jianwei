## 配置前必须完成

在百炼电脑端控制台的“免费额度”页找到 **qwen3.7-flash**，确认仍有未过期额度，开启该模型的 **免费额度用完即停**，等待配置生效后再调用。已认证用户的免费额度耗尽后可能转为按量付费，开通模型本身不等于已经开启此保护。

官方文档说明，保护生效后额度耗尽返回 HTTP 403 / `AllocationQuota.FreeTierOnly`。配置变更存在生效延迟，在延迟期间调用仍可能产生费用。应用无法读取或验证你的控制台开关、余额、剩余免费额度或实际账单，服务端确认值也只是用户确认，不是独立核验。若模型显示“不支持开启”或额度已耗尽/过期，在本次 ¥0 预算下保持真实模式关闭。

从同一北京业务空间创建专用 API Key，并仅配置到服务端：

| 服务端变量 | 配置方式 |
|---|---|
| `DASHSCOPE_API_KEY` | 真实 API Key，必须设为密钥（secret），不可使用 `NEXT_PUBLIC_` 前缀 |
| `QWEN_FREE_TIER_ONLY_CONFIRMED` | 默认 `false`；只有上述保护已生效后才设为字符串 `true` |

线上运行时变量由网站托管配置管理；修改后需要重新部署使配置生效。本地变量不等于线上变量。Base URL 和模型名已固定在公共配置模块，页面或资料内容不能覆盖地址，避免把密钥发送到其他服务。不要把密钥写入聊天、代码、Git、研究资料或导出文件。页面只读取配置布尔状态，不回传密钥或其片段。

## 首轮验证

1. 创建研究项目、确认范围，导入少量明确来源的资料。若只验证接口，可使用明确标识的虚构演示资料；这不构成真实市场证据。
2. 打开“执行与评测”，选择 Qwen3.7-Plus，点击“刷新模型配置状态”，确认服务端密钥与免费保护确认均已配置。
3. 选择单角色，保持尝试上限 **1**，勾选此次免费额度保护确认，创建执行。创建不会调用百炼。
4. 点击“只推进下一步”：这一条研究请求同时验证鉴权、连通性、结构与引用边界。正常研究执行没有额外的 hello 请求，也没有隐式重试；故障诊断另有不生成文本的固定端点检查。
5. 成功后继续推进本地校验和草稿保存；这两步不增加模型请求。检查原文能否支持判断、反证是否保留、付费强度是否越界、计划是否可执行。
6. 核对请求回执中的输入/输出词元、请求编号及百炼额度/账单。应用显示付费预算 ¥0，不把未核对账单写成实际费用 ¥0。没有回执的请求用量未知，不能按零计。

单角色首测成功并人工核查后，才使用同一资料运行四角色，默认四次请求。四个角色一致不能当作四份独立市场证据。`qwen3.7-flash` 是模型别名，后续正式质量比较应固定可用快照、资料版本、执行器与提示词版本。

## 失败与验证边界

鉴权失败、403 配额耗尽、429 限流、网络中断、超时、输出截断、结构错误或引用越界都会停止。单角色默认一次尝试，失败后不能绕过预算重试。不会退回非结构化输出，不切换付费或其他模型。暂停与取消可以拒绝迟到结果，但不能撤销已到达百炼的请求或保证没有用量。

14 组固定流程评测始终使用模拟适配器，即使页面选择 Qwen，也不会批量消耗真实额度。自动检查只验证结构和引用标识归属，不证明语义正确、商业结论可靠或提示注入抵抗能力。
