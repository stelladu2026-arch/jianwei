# 批量链接导入

证据库新增“批量链接导入”，每行一个链接，每批最多6个，读取预览后勾选并确认有权使用，沿用现有导入 CAS/幂等保存。仅生成预览不修改项目、不运行模型或搜索。

支持 GitHub Issue 作者正文（不读取评论、不混入机器人回复）、GitHub Markdown/MDX/TXT 文档，以及 dify.ai、www.dify.ai、docs.dify.ai、help.aliyun.com 的可定位正文网页。其他站点明确提示改用文件/粘贴。网页始终标为抽取片段，超过8000字符的资料标为裁剪，入库保留该标记。Issue 日期、作者、状态及来源链接保留；关闭状态不等于已修复。

网络限定HTTPS固定站点，拒绝账号信息、端口、自动重定向；不传密钥、Cookie或第三方凭据。每条超时10秒、最大600KB、并发2，无自动重试。公开读取失败不影响已成功预览项；原导入入口保留。

验证：新增6组离线用例覆盖目标限制、正文与元数据、重定向/机器人/空正文/超大响应、裁剪/网页抽取、批次数量/去重/同源、导入截断标记与重复跳过。完整离线API回归、生产构建含类型检查通过。没有真实模型调用；实际外站可达性和浏览器交互仍需独立验收。外站限流、动态渲染、改版或跳转可能造成单项失败。
