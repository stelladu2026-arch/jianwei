# 等待反馈与执行状态同步 — 2026-10-17

在一键研究与独立执行中，提交阶段即显示等待反馈；每秒显示已等待时长，阶段提示随时间切换。已确认执行中使用动态圆环、状态点、当前步骤呼吸和不定进度条。动画不表示真实完成比例，不显示虚构剩余时间。耗时较长时提示核对检查点；失效或缺失执行标识时显示状态待确认并停止运行动画。暂停、取消、失败、完成或依据变更也停止动画。尊重减少动态效果偏好，并保持屏幕阅读器不会每秒播报计时。

修复先前等待执行标识才开始轮询的问题：前端 POST 尚未返回时即启动串行检查点读取。轮询不调用模型、不重复提交步骤。清理后不发布旧读取结果；根工作台仅接纳不低于当前版本的项目更新，避免迟到读取覆盖暂停或成功交付。原有 CAS、预算、租约与人工确认不变。

新增八项离线检查覆盖提交与已确认运行的区别、计时与动态提示、长等待、未知时长、过期标识、所有结束状态的动画停止及旧状态覆盖保护。静态 React 验证不能代替真实动画与移动端视觉验收；本轮没有模型调用。
