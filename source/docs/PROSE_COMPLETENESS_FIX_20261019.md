# 研究文案只剩单字符：修复与边界

## 证据与判断

用户截图中固定说明完整，但模型生成的标题、结论、研究问题、行动、反证和未知项仅显示一个汉字。代码渲染直接使用对应完整字段，没有取首字的映射。
前一版将自由正文的生成格式统一加上了 pattern=\\S。该表达式只描述一个非空字符，可能被生成端按完整匹配解释，和截图症状一致；这属于依据截图与代码的推断，未通过真实模型 A/B 确证。
官方结构化输出文档确认 pattern 作用于字符串约束，但未说明上述匹配边界：https://www.alibabacloud.com/help/en/model-studio/qwen-structured-output 。

## 修复

- 从自由分析正文移除 pattern，保留字符长度、类型、枚举、引用、原文定位与服务端 trim 非空检查。规划关键词的完整格式匹配保持不变。
- 提示词明确要求完整语句、条件性结论与具体下一步，不使用单字占位，不编造缺失证据。
- 多处单字符旧草稿显示内容可能未完整生成的提示。不自动补写、不更改已保存输出，不以界面格式冒充恢复全文。
- 已完成的单角色草稿也可显式“使用已采集资料重新分析”。旧轮、旧机会卡与累计预算保留；新轮最多两次模型请求，默认一次分析，无采集、无自动重试。
- 有运行请求、四角色、暂停项目或未完成复核时仍禁止这条恢复路径。版本冲突、幂等与晚到结果规则保持不变。
- 摘要长段落、长编号和窄屏列允许换行，正文段落分隔原样保留。
