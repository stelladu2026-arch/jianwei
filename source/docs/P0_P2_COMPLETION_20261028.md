# P0–P2 实现核对

## P0
逐次模型回执作为页面与报告共同统计源，准备阶段本地失败不增加模型请求。已有同版本完成研究可以派生导出更新统计，原保存结果不改写。当前修复继续区分补证所受的模型/来源/检索预算。

## P1
规划提示要求角色、业务动作与问题后果，泛化关键词只记录范围提示，不隐式补搜或重试。分析资料按研究范围与关键词词面重叠稳定排序，保留所有候选资料，沿用先前引用、来源均衡与反证优先策略及最终输入上限。排序不是语义支持判定。

用途提示区分开发任务、推广、文档功能说明、问题/需求报告、背景统计和待核查资料。Issue 应用附注与作者正文分离；旧前缀不作为官方原话。模型必须区分假设与来源、保留未知、付款无依据时不升级；新用途协议进入 Harness 绑定与恢复兼容性检查。

## P2
验证计划提示要求对象、动作、观察指标、继续/停止条件。缺少显式指标/条件时在界面与新分析报告提示人工完善，不编造行动或自动修复历史输出。

报告新增阅读主文：判断、替代、关键引用、用途边界、反证未知与逐段下一步。完整执行分类及原文保留在可展开附录，部分完成且尚无已接受报告时保留原阶段报告。没有删改原始资料或保存的模型输出。未知 gap 未单列与机会草稿已列的 unknowns 分别表述，避免“未知：无”。

## 验证与边界
默认完整离线 API 回归通过；生产构建含 TypeScript 通过。P0–P2 新增排序保全/稳定性、中英文匹配、泛词提示、阅读主文与完整附录不丢失等3组用例；其余来源归属、回执、计划提示及 Harness 漂移用例随完整套件通过。

本轮真实模型/公开来源调用0。功能实现与离线验收完成，不表示检索召回率、模型语义判断、跨站覆盖或报告商业质量已通过真实评测。新提示效果需用户手动真实验收。此前来源归属批次上传被自动审批拒绝，合并包尚未上传/部署，等待针对本轮合并批次的明确上传授权。
