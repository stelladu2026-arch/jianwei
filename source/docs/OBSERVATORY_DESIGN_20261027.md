# 见微：深空研究观测站

用户选择方案 C，并要求字体增大。

- 首页：石墨黑、冰白、青色轨道、荧光绿决策轴；背景是独立装饰素材，无图片文字。所有正文、按钮、导航和证据卡仍为真实 HTML。
- 三个证据视角可通过点击及键盘左右箭头/Home/End切换；原文、反证、判断使用既有虚构案例，持续标注演示边界。
- 桌面标题 52–80px、正文 18–23px、操作 18–19px；手机标题约 39px、主要正文18–20px。窄屏证据卡纵向排列，无倾斜小字。
- 进场仅做一次短距离淡入；悬停卡片抬升、选择态高亮、内容切换。支持减少动态效果，不添加无限转动、假进度或滚动劫持。
- 工作台统一深色阅读表面，放大正文、主要控件与次要说明；保留现有业务/API/预算/引用规则。
- 背景 WebP 约133KB，无新增JS依赖。完整背景原图仅用于编码，未作为整页截图。

部署应使用现有 Production 配置做暂存验收，不将生产数据库密钥扩散到所有 Preview。`vercel-interview-check.mjs` 只读验证密码边界与数据库表结构，失败中止构建；不读取记录，不写数据，不请求模型。正式域名保持当前版本。

验证：最终本地构建与类型检查以运行结果为准。受此前浏览器安全策略限制，本轮不声称已完成真实浏览器的版式/动画验收。
