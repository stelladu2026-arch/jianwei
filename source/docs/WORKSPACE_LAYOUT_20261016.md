# 研究入口与执行页排版整理

一键研究按研究方式与资料、本轮请求与确认、开始条件、主操作的顺序排列。配置状态和刷新按钮固定在同一行，已由开始条件提供的提示不再在上方重复。继续执行前的免费额度确认移到操作按钮之前。

独立执行的配置字段使用等宽网格，新建按钮放在配置卡底部；真实模式保留常显的配置状态与免费额度确认，服务地址和环境变量说明收进可展开区域。主操作左侧显示本次请求上限，当前执行的继续、暂停、结束集中在对应记录内。

恢复提示按原因与操作对齐；长按钮允许换行，窄屏改为纵向排列。执行页资源与评测卡在空间不足时排到主栏下方，避免挤压配置表单。没有改变模型请求、预算、恢复约束、引用校验或项目数据。

验证：387 项现有离线路由和组件检查、TypeScript、托管生产构建通过。没有新增真实模型或来源请求。浏览器视觉、点击、键盘与具体设备布局仍待人工验收，离线检查不等于浏览器验收。
