# 全站材质与阅读节奏整理

用户要求：导览卡片更接近选定效果图；统一修复浅底浅字冲突；改善控件、卡片和正文的粘连。

## 改动

- 在旧 globals / research-desk 样式源头将浅色背景与硬编码文字色转换为已有主题变量；不改变根默认值与暗色品牌背景。消除依赖 !important 的浅色卡片底色。
- 独立 workspace-polish 层统一表单、流程、执行、角色、报告结论、状态、引用、弹窗/抽屉等表面；危险、警告与完成态继续使用不同语义色。
- 控件组 12–16px，内容间隔 24–32px，正文行距 1.8–1.9。卡片内边距桌面24–36px、手机20–24px；保留窄屏换行和上一版证据库自适应。
- 导览卡片使用错落位置、左右透视、低透明度表面、3px背景模糊和独立后层。移动端及减少动态效果模式保持正向布局，支持键盘切换。
- 保留用户选择的完整工作台免密码访问。本次无业务、数据库、模型调用或预算规则变更。

## 验证边界

- 本地生产构建及类型检查通过；最终远端构建覆盖最终样式。
