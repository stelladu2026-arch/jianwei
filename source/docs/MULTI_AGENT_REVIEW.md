# v0.6 四角色原文核查与对照

在“一键研究”中选择“四角色复核已有资料”。需要已确认范围和至少一条可用真实正文，不采集新资料、不规划、不补搜；四角色各一次真实请求，总上限 4，无自动重试。各角色共用 Qwen3.7-Plus，服务端密钥与免费保护配置沿用。每个角色最多两条笔记。

|角色|可读输入|输出与权限|
|---|---|---|
|需求分析|同一冻结范围、原文及当前有效项目记忆|需求与条件主张；不能写正式机会|
|替代与商业|同一原文、记忆、需求摘要|替代与商业假设；价格不升级为成交|
|独立反证|同一原文；无前序结论、无解释性记忆|反例、覆盖偏差与未证实项|
|协调汇总|同一原文、记忆与前三角色有界摘要|综合草稿、逐项核查及待核查分歧|

每条笔记以及最终问题/结论，必须分别给出支持、部分支持、证据不足或矛盾的模型判断。除证据不足外必须附连续原文片段；Schema 给出从冻结原文逐字切出的片段枚举供模型选择；片段只能引用该主张声明的输入资料。代码核对片段逐字存在并保存位置，不使用模糊匹配或改写来修补。位置通过不证明模型支持度标签正确。前序摘要最多 1100 字符，完整输出另存；单个任务输入最多 16000 字符，不含固定系统提示和输出结构。

如果已有同范围/资料版本的真实单角色草稿，直接复用其实际输入片段；当前记忆也相同才标为匹配。无基线时仅做四角色核查，不额外生成。展示的单角色请求/用量仅是分析，不把旧规划和缺口请求混入；四角色计入全部四次分析。缓存不同时间的对照不是随机实验，角色提示和核查契约均为本次干预，不能据单例宣布准确率或架构优劣。

人工评审要覆盖两份草稿的每条主张，记录支持程度、纠正依据和结论。只有人工提交后才保存，保存不调用模型。输入不匹配时只能暂不判定。正式机会卡、正式报告和已验证经验均需原有人工流程。模型角色分歧是待核查建议，可转到“治理”记录人工纠正与反思；不自动确认经验、不跨项目传播。

暂停、范围/资料/记忆变化及过期租约按原有版本与检查点治理；不接收迟到结果。失败请求仍占已预约调用预算，四角色本轮不追加模型重试；本地校验与草稿保存可按原有两次限制恢复。用量缺失保留未知，不记为零。付费预算 ¥0；免费保护是用户确认，费用以百炼账单为准。

首轮真实验收停在反证引文核对，没有完整四角色草稿；查看已通过的需求/商业角色即可。后续真实完整验收需新一轮预算确认。

网页人工验收：打开已完成四角色研究，逐条“查看原文”；比较两份主张是否过强；完成人工对照保存并刷新确认仍存在。此操作无需重新配置密钥或运行新的研究。


## 失败后如何重新开始

打开“一键研究”的“下一步怎么处理”区，展开“查看失败详情”。四角色模型阶段失败时，原轮不再追加重试；若已处理原因，可勾选新一轮免费额度及最多 4 次确认，再点击“保留记录并重新开始四角色复核”。页面从需求分析自动推进，旧轮错误和用量在“前两轮研究记录”中查看。只想停止时点击“保留记录并结束本轮”，它不调用模型。

本地引用校验和草稿保存失败仍使用原来的本地重试入口，不新增模型请求。额度耗尽时先在百炼核查额度；修复版本并不保证每次真实生成都会通过，重新开始仍有明确的新增调用成本和失败即停规则。

原文片段枚举后的第二轮新增 3 次真实请求。需求及商业角色合计 4 个核查条目、7 处引文定位通过；独立反证在严格核查格式校验时停止（`INVALID_REVIEW_COVERAGE`）。此码可能涉及缺失/重复条目、角色不允许的字段或缺少必要引用；旧失败回执没有更细字段，也不保留拒绝输出，不能确定具体分支。没有协调汇总、完整报告和人工质量对照。

后续离线修复为各拒绝分支记录安全字段路径，保留严格引文与覆盖要求，新增通用恢复指引。完整真实验收仍未通过，Qwen 免费额度确认恢复前不再调用；网页的“配置已就绪”仅表示密钥及保护配置，不能代表剩余额度已恢复。
