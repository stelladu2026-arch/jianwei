# 结论引用范围与报告可读性

结论摘要增加本地计算的引用范围：已附原文/引用编号、来源关联组、裁剪片段，以及未附原文、同作者/线程集中、Show HN 展示帖和公开资料的限制。只统计当前结论实际引用的保存片段，不把所有项目资料都计入该结论的依据。

- 来源关联组沿用保守合并规则，只描述已保存资料之间的关系，不是独立客户数量或语义可信度。
- 作者或线程未保存在输入快照中时保留未知，不从当前项目回填历史身份。展开原文和原有人工复核入口保留。
- Show HN 只按标题识别项目展示线索，不自动判断作者身份、真实客户需求或是否付款。
- 规范页面与新生成报告的来源分组表述；修正“没有自动保存机会卡”和实际自动保存待确认草稿之间的文案歧义。
- 新模型请求统一要求简体中文分析、中文解释在前的术语；英文检索词、逐字引文、编号、协议枚举保持原样。已有英文报告和被拒输出不翻译、改写或重新接纳。

新生成 Markdown 报告包含同样的范围提示。已有报告文本保持原样；页面可依据其保存的输入快照展示本地范围提示。此功能不自动接受或否定模型结论，不计算准确率，不确认机会卡、市场需求或记忆。
