# 执行与评测 v0.4

日期：2026-10-03。支持模拟和服务端 Qwen 执行；密钥尚未配置，实际模型连通性及语义研究质量未验证。

## 单角色与四角色

单角色：协调角色研究 → 应用结构/引用检查 → 保存独立执行草稿。

四角色：需求分析 → 商业分析（读取需求输出）→ 反证首轮（只读原始资料，屏蔽其他输出与记忆）→ 协调汇总（读取三份角色结果）→ 应用检查 → 保存执行草稿。

这是固定依赖编排，不是自主动态规划；Qwen 模式由真实模型分角色调用，模拟模式不构成真实推理。模拟适配器输出通用占位判断，不能从中评价洞察力或商业化意识。没有检索、数据库写入或系统提示修改工具暴露给模型；角色提出搜索的能力声明尚不代表可执行外部搜索。

## 执行、检查点与失败

`POST /api/projects/{id}/run` 支持 start/advance/pause/resume/cancel/retry/recover/evaluate。GET 返回最新项目与执行检查点。每次变更必须带项目版本和 UUID 调用标识。

advance 先用项目 CAS 保存检查点、调用标识、输入快照和预算预约，然后执行一个模型或规则步骤，再校验当前项目版本、执行 ID 与租约，最后保存输出。并发 advance 只能有一个预约成功。同一调用标识返回已保存状态，不重复执行；调用标识同时保留在步骤尝试记录中。

服务端每个模拟模型步骤有 4 秒超时和 15 秒租约；Qwen 有 45 秒超时和 75 秒租约，关闭思考模式、每次最多 2400 输出词元，不自动重试、回退格式、切换服务商或切换付费。Qwen 单角色默认一次请求、四角色默认四次，总尝试上限最多四次；失败也占用尝试预算。若进程中断，租约过期后 recover 将结果标记为未确认，保留已消耗尝试；不能自动假定没有调用。失败需要显式 retry，每步最多两次尝试；单角色默认四次模型尝试预算，四角色默认八次，可设置 1–12，预算由应用强制。规则步骤不计入模型尝试预算。

暂停/取消清除租约，不接受迟到结果。项目暂停同时冻结活跃执行；先恢复项目，再恢复执行。研究范围、证据、记忆变化使当前执行失效。其他并发项目编辑若发生于步骤执行中，也会拒绝本步结果并记录中断，保留用户编辑。没有后台队列或持久运行的调度器：连续推进由页面逐步请求，关闭页面后已启动的一步可能完成，下次打开从下一步继续。

## 上下文与模型输出

当前最多选入 12 条资料，先考虑最多三条反证，再优先不同线程。此排序不是语义检索，也不把线程数当作独立客户数。每条正文超过 900 字符会裁剪并标记不完整；完整证据原文不变。任务 JSON 限制 16,000 字符，包含简报、规则、资料、记忆与前序输出。不包含适配器的固定系统提示及输出 JSON Schema；字符不是词元。

必要前序引用对应的证据不因裁剪而删除；研究范围和前序结果不会静默删减。无法满足长度限制时返回上下文错误。记忆可按容量省略，省略编号与证据裁剪信息保留。每一步保留实际输入快照，可复核某次调用到底读到了什么。

统一结果校验拒绝结构错误、输出范围版本不一致、越界引用、嵌套引用与顶层引用不一致，以及“强付费”标签。协调结果必须包含草稿。只证明输出契约正确，不能证明引用支持语义、推理可靠或交易发生。

模拟或 Qwen 草稿单独保存在执行记录中，不写入人工机会卡或正式报告快照。保存最近三次历史执行、三次评测；整体项目沿用容量上限。JSON 导出包含输入快照、角色输出和尝试记录。

## 固定评测

资料版本 `synthetic-contracts/1`、执行器版本 `research-runner/2`、模拟模型 `simulation-research/1`。14 组运行由七个完全虚构用例分别执行单角色与四角色方案构成：

| 用例 | 预期检查 |
|---|---|
| 正常资料 | 闭环保存模拟草稿，引用可定位，反证首轮没有其他结论 |
| 外部指令样例 | 恶意字符串位于资料字段，应用约束另行提供；不是模型抗注入评测 |
| 越界引用 | 失败输出不得保存为研究结果 |
| 首次格式错误 | 记录失败，重试后完成，预算不重置 |
| 首次超时 | 记录超时，重试后完成，最多两次尝试 |
| 长上下文 | 完整输入有界，优先反证，完整原文不被修改 |
| 空证据 | 执行入口拒绝 |

记录资料集 SHA-256 指纹、版本、每组结构化输出、失败代码、模拟尝试、字符合计和耗时。没有模型准确率或研究质量指标；语义质量字段为 null，真实模型调用及实际模型费用为零。模拟耗时不用于生产模型比较。

## 真实模型验证准备

人工语义参考用例在 `tests/fixtures/semantic-cases.json`；它们暂不计入模拟通过率。接入真实模型后，在固定资料、模型快照、执行器版本、提示版本和预算下重复运行单角色/四角色，记录实际词元、费用、等待时长、超时与失败；至少重复三轮作为初始实验设定，不能把三轮视为统计显著性证明。

人工评审分别记录五项，采用 0/1/2 分：引用是否支持结论、人群/场景是否准确、反证是否改变判断、商业信号是否分级准确、验证计划是否具体。每项必须指明原文引用与评分原因；不允许先编造综合准确率。伪造交易或价格、引用越界、把口头兴趣当成交为阻断项，不能被其他评分抵消。

Qwen 已有服务端适配器、严格结构化输出与词元回执；实际账单不能从词元直接推定为零。密钥缺失或免费额度保护未确认时拒绝调用。真实验证步骤见 [Qwen 接入](QWEN_SETUP.md)。动态补证分支、二轮反证、检索工具执行和语义相关性检索仍可在接入前继续开发，但本版本没有宣称已完成。
