# 单角色引文协议与原文恢复 — 2026-10-17

单角色的新请求采用 citation-selections/1，引文只选择当前输入目录的 Q 编号，由程序附回同一片段。模型不再抄写或翻译引文。目录随每次模型输入生成，工具带回新资料后只使用该次输入的目录。旧自由文本引文仍按原规则严格校验，不修补、替换或接纳历史失败输出。未知、重复、未被主张引用的编号、混入自由引文、缺少协议标记均拒绝。保持最多两条模型选择与四条最终引用容量；选择引文不代表语义支持或市场已核实。

工作流升级 opportunity-workflow/6。单角色失败后增加“使用已采集资料重新分析”：操作者单独确认免费额度保护和新轮最多两次请求，才可创建新轮。创建动作本身不调用模型。新轮默认分析一次，跳过规划、采集、工具和补搜；随后本地校验并保存待人工确认草稿。失败不自动重试，剩余一次只能显式准备重试。旧轮及项目累计模型、来源与采集用量不清零。旧失败记录原样存入现有两轮历史窗口。

该恢复不适用于四角色、执行中租约、暂停/归档项目、虚构或无正文资料、尚有执行与评测任务或未结束的结论复核。版本冲突、幂等及迟到结果边界保持。用户编辑资料时，新输入胜过迟到输出。当前仅提供单角色恢复，不把四角色缺失的独立核查跳过后标成完整多角色结果。

界面明确请求上限覆盖整轮，包括规划、工具后的继续分析与重试；账户免费额度不能从应用请求数推断。失败文案显示“流程未完成 · 已有成果保留”，阶段成果和原文仍可导出。没有额外确认就不会为旧轮增加上限或自动创建恢复轮。
