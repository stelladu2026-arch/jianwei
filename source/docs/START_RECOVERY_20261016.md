# 新一轮研究开始条件与恢复入口

## 行为调整

开始按钮使用统一的可用条件列表，显示未满足项与直接处理入口：研究范围、项目状态、现有任务、有效正文、模型配置和本轮免费保护确认。刷新后仍需操作者主动确认预算，不代为勾选。

公开采集采用项目累计上限，结束旧轮不会清零。Hacker News 与百科流程开始前预留最多三次采集，V2EX 节点采样预留一次；前后端共用 `collectionStartBlocker`，剩余次数或资料容量不足时提前给出原因。

- 可以“切换为已有资料复核”，该操作只切换模式；仍需确认预算并点击开始。
- 可以“沿用范围新建研究”，先打开预填简报表单，由操作者确认创建。只复制范围字段，不复制资料、结论、记忆、执行状态或历史用量，也不修改旧项目。
- 证据库的“使用已有资料研究”直接进入四角色模式；项目累计采集与本轮模型请求次数分别说明。
- 四角色失败后的重新开始按钮也显示未满足条件与恢复入口；结论复核未结束时明确引导处理检查点。
- 新建简报的保存错误在表单内展示。

规划输出的提供方 Schema 同时限制一至三个英文关键词，与既有运行时字符、长度和词数检查配合。已有被拒中文关键词不会被翻译、改写或重新接纳。

## 离线验证

新增 12 项检查，共 380 项离线检查通过，类型检查通过。覆盖累计用量保留、公开与国内来源准入一致性、模式切换、多个禁用原因、恢复按钮回调、资料容量、简报白名单、真实 SQLite 检查点创建与显式新建项目、规划关键词约束。

测试均使用虚构数据，不调用真实模型。浏览器点击与排版需人工验收；本文不包含实际运行编号、真实模型用量或私有部署信息。
