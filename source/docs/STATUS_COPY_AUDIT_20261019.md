# 状态和提示文案去重检查

## 检查范围与改动

本轮检查研究简报、一键研究、执行与评测、机会判断、阶段成果、服务配置与编辑/导入弹窗的提示渲染。

1. 研究简报：确认后只显示一处“范围已确认”，保留“编辑后需重新确认”的说明及研究入口；隐藏已无操作意义的禁用确认按钮。未确认、保存中、演示态保持各自限制。
2. 一键研究：检查点标题固定，动态执行状态交由研究进程展示。停止原因集中在恢复区；各错误字段保留，重复中文原因只说明一次；完整错误与阶段记录继续可查。预算已耗尽时不再重复提示相同原因或给出相反的“仍可重试”泛化说明。
3. 研究启动：正常就绪不显示额外成功提示。服务配置在其状态栏内显示一次，开始前清单跳过已被该栏覆盖的服务问题；其他阻塞原因和直接操作保留。
4. 执行与评测：配置错误在服务状态栏中说明及刷新；范围待确认、缺原文、项目暂停或未结束工作不再被配置底部的通用阻塞提示重复复述；按钮限制和原校验不改。
5. 阶段成果：嵌入一键研究时不再重复停止原因；已有完整草稿时不再重复同一结论摘要。独立阶段报告仍默认显示原因和结论，导出与原文/分析/下一步保持可用。
6. 机会卡：由结论摘要统一展示建议和草稿/历史状态；删除外层重复标签。仅省略精确匹配的系统自动草稿提醒，人工理由和范围变更原因保留。
7. 同一来源失败的通用提示按最终显示消息去重；每次请求和渠道明细仍完整保存在执行记录，未改模型内容或历史数据。
8. 编辑范围、导入及机会编辑弹窗开启时，操作错误仅显示在当前表单；关闭弹窗后仍可在工作区显示，不在遮罩背后重复展示。

## 验证

新增 tests/status-copy-smoke.mjs，6 组 React 渲染及操作检查：确认成功仅一条提示、未确认操作、演示/保存禁用、就绪静默、已覆盖服务错误不重复且其他原因可操作、嵌入报告去重但原文及下一步完整。
全量回归 536 项 PASS；存储配置 49 项 PASS。类型检查通过，生产构建及发布状态见交付记录。
只改展示条件，不改确认状态、权限、请求预算、引用规则、模型协议或存储内容；本轮没有模型调用及生产数据读写。
本地验证为静态 React 渲染及接口回归，未声称完成生产浏览器逐屏视觉验收。
