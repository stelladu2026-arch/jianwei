# 面试作品导览改造（2026-10-27）

## 改动

- 新默认入口为作品导览：项目定位、原文/反证/判断交互、三项产品取舍、研究链路与研究空间入口。
- 导览可在原文、反证和判断间用点击、方向键、Home/End 切换；案例始终标记虚构。
- 工作台保留原导航、表单与事件，重新组织字体、色彩、列表、主按钮与结论阅读层级。
- 创建演示时禁用切换研究空间，防止迟到的创建结果劫持导航。
- 视图改变时恢复主区焦点并回到顶部；原机会卡定位效果仍后执行。

## 实际采用的资料

- Anthropic frontend-design：基于研究对象选择视觉概念，先明确计划再实现；突出字体和一处记忆点。
- UI/UX Pro Max：执行系统与动效检索，拒绝与本项目不贴合的系统结果；采用触达、对比度、焦点和减少动态效果规范。
- Taste Skill：先区分作品展示和操作工作台，选择 one-motif；保留原取景标记，避免把图案当内容。
- Impeccable：阅读新的视觉工作流程、质量下限与模式划分。上下文启动器的网络授权未完成，改为直接读取仓库上下文；未声称完成它的方向投票或全流程工具检查。
- Hallmark：读取重设计、自定义方向、排版、状态与检查规范；运行 scaffold、改前与改后静态检查，并执行独立代码复核。
- Originkit：https://www.originkit.dev/ ，作为用户指定的交互参考检索；未复制其组件、引入其依赖，或声称在本轮浏览器中验证了该站组件。

## 验证

- 599 项现有离线回归通过，完整完成标记已出现；没有真实模型调用。
- 类型检查与 Next.js 生产构建通过；最终小改后的检查结果见本次提交记录。
- Hallmark 静态检查：0 FAIL、2 WARN。两项警告为：同一 token 集中存在深色前景/浅色工作台背景组合的启发式提醒；作品页与紧凑工作台及不同断点的列间距不同。前者由各容器显式设置前景色，后者保留两种场景的密度差异。
- 8 个指定核心色对计算对比度为 6.58:1 至 15.66:1；仅为 token 的数学计算，不是整站可访问性认证。
- 独立只读复核覆盖视图、API 边界、引用、键盘与 CSS，发现的创建竞态及导航焦点问题已修正。没有用代码审查代替视觉评价。
- 新版实际桌面/手机截图与动效观感未验收，原因见 DESIGN.md。
