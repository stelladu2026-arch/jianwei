# 异常状态与恢复入口审查

日期：2026-10-05。覆盖项目管理、范围确认、一键研究、独立执行与评测、资料检索与导入、机会/报告、角色上下文、项目记忆和反思。此次只运行离线测试与构建，不消耗 Qwen 免费额度。审查关注“原因是否清楚、下一步是否有实际入口、不可执行的操作是否在点击前说明”。

| 情况 | 原有问题 | 已调整的指引或操作 |
|---|---|---|
| 手动研究进入执行页 | 按钮永久禁用且仍绑定演示步骤 | 可点击进入“执行与评测”，真实调用仍需单独配置及额度确认 |
| 项目暂停、取消、完成或归档 | 子页面只提示不能执行，缺恢复入口 | 项目上方显示恢复/重新开启按钮，分别使用已有恢复与范围确认动作；不重置调用预算 |
| 单角色或独立执行预算耗尽 | 仍可点击重试然后被服务器拒绝 | 共用服务端资格守卫，禁用无效重试、说明原因；可保留记录并结束，再明确预算新建执行 |
| 四角色模型阶段失败 | 原轮不能重试却无可操作指引 | 显示失败详情，新轮最多四次确认与原子重启入口；旧用量保留；失败即停 |
| 本地校验或保存失败 | 容易误认为须等模型额度 | 合规本地步骤恢复不要求模型密钥或额度确认，也不新增模型请求 |
| 工作流与独立执行互斥 | 点击后才报冲突 | 显示未结束任务及前往对应页面的处理按钮，禁用冲突操作 |
| 输入依据变化、部分完成或取消 | 仅显示状态，缺少下一步 | 核对范围、去证据库补原文或重新开轮的指引；旧依据不能接着推进 |
| 采集失败或零新增 | 短暂通知，容易误认为没有需求 | 持续错误/结果提示，保留原文，提示调整检索或导入资料；预算满时不发无效搜索 |
| 新导入文件读取失败 | 旧文件资料可能还被选中 | 新读取先清除旧预览；阻止失败文件提交，支持重新选择或改为手动粘贴；丢弃迟到的旧文件读取 |
| 登录页、网络中断、响应不完整 | JSON 解析报错无法理解，重提可能重复写入 | 持续说明重新打开网页、确认账号及刷新项目；写请求不自动重放，先确认服务端结果 |
| 记忆已过期或依据变化 | 仍显示可以确认，点击后拒绝 | 显示编辑并重新保存指引，再记录验证；不把失效记忆纳入模型输入 |
| 规则反思未修复 | 提交关闭时才被拒绝 | 显示实际尚未解决的问题及前往工作流/执行/证据/机会的按钮 |
| 报告尚不能确认完成 | 未补计划仍可点击完成 | 按范围、机会及计划资格禁用完成，显示去补充与复核入口 |
| 旧引用与未完成对照 | 点击已删除原文或等待评审没有明确原因 | 已删除引用说明历史快照入口；机会编辑可显式移除失效引用；未完成对照及未逐条评审显示条件 |
| 核查格式错误 | 单一错误码，无法区分字段 | 增加安全字段路径；不保存被拒原文、不放宽引用或覆盖校验 |

验证：原有 175 项加 10 项通用恢复回归共 185 项通过，类型检查通过。新增回归包括认证网页、网络写入不重放、版本冲突、坏响应后显式刷新、预算与本地步骤守卫、四角色停止及安全字段定位。全部模拟请求，不是模型质量或网页视觉测试。

人工网页复验：刷新见微后，检查失败研究是否显示“下一步怎么处理”与历史记录；从工作台进入执行页；在未完成检查点时使用前往处理按钮；查看失效记忆/未修复反思的指引；在导入窗口先选正确文件再选坏文件，确认不能提交旧预览；检查未补验证计划时完成按钮有原因与入口。以上无需新的模型请求。
