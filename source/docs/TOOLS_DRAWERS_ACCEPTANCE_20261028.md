# 方案 A：顶部入口与右侧抽屉

报告页顶部提供保存与导出入口，原保存、完成确认、导出和历史版本内容移入抽屉。执行页顶部显示模型步骤尝试及上限（不是请求数），资源明细与虚构流程评测移入抽屉。失败和预算耗尽提示仍保留在主执行区域。

复用 Radix Sheet 的焦点管理、Esc 关闭和触发器焦点返回；独立滚动，移动端自适应宽度，减少动态效果偏好下关闭抽屉动画。抽屉使用独立样式以适配 Portal，避免依赖主页面祖先。

验收：打开已有项目，分别检查两个入口、关闭后正文位置、键盘操作、窄屏、历史版本切换及已有禁用条件。未触发真实模型调用。生产构建及类型检查通过后生成独立版本；视觉与交互最终效果待浏览器验收。
