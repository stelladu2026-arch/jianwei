# 产品审查修复 2026-10-29

本批覆盖稳定性、证据资格、渠道主题匹配、部分结果展示和人工验证记录。持续授权允许代码上传与独立验收部署，不涉及正式发布、真实模型调用或新增付费。

## 已实现
- 发布时必检数据库连接、模型密钥格式、免费保护标记和访问密码；只输出布尔检查，不发模型生成请求。任一缺项使发布构建失败，避免“构建成功但无法使用”。免费保护标记不代表已独立核验供应商额度。
- 共用原文资格函数：搜索/订阅摘要保留供查看，不计入已有资料分析、四角色冻结及词面/向量检索原文。已有裁剪原文可用，摘要不冒充原文；导入界面可区分原文与转述。
- 原文与摘要分别计数；原文不足显示本轮已结束、未形成判断；服务提示区分缺密钥、缺保护与状态读取异常。数据库错误不再写死 Production。
- 社区按研究产品匹配，不匹配不请求。网页发现预留一次回源空间，预算内优先读取已支持站点（GitHub Issue/文本文件、Dify、阿里云帮助与允许列表 Discourse 主题）；未支持主机不自动请求，不绕过访问限制。原文回源失败保留摘要和原因，不额外重试。
- 单阶段执行收进高级选项，多角色说明标明进一步核查用途及未证实收益。
- 验证面板新增假设、对象、动作、指标/记录方法、继续停止条件、实际结果和资料引用。记录结果必须引用本项目原文；活跃研究未结束时拒绝写入；结果保存后机会卡待人工复核，不自动提升为事实或调用模型。原研究报告不改写；项目报告/JSON 导出包含实验记录。机会删除时清理对应记录。
- 来源与证据边界策略版本升级，旧检查点不静默混用新策略。

## 验证与边界
新增离线回归覆盖摘要资格、社区主题匹配、固定目的地回源、实验依据与人工复核、配置就绪检查。原多渠道用例中“全部摘要都应传入分析”的断言改为仅合格原文；不是放宽引用校验。完整 API 回归、TypeScript 与 Next 构建结果以本轮实际运行和云端日志为准；没有真实模型调用。

此版本不是全部审查建议均已完成：渠道仍采用有界固定配额并增加原文预留，尚未实现按证据缺口动态重新分配；不支持任意网站正文提取；实验是人工录入，不自动执行访谈/业务实验；单多角色收益待真实对照。没有将结构校验当语义正确性，也不将原文可读等同于需求成立。浏览器完整交互和新研究语义质量待真实验收。
