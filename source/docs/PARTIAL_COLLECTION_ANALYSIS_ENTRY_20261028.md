# 采集不足状态的已有资料分析入口

根因：partial 是已结束的部分成果状态，界面现有资料入口和服务器 existingAnalysisBlockReason 却只允许 failed/completed。新导入资料会使旧轮 stale，新项目未建立旧轮也没有可用入口，用户因此继续点自动采集。

修复：设置区顶部明确显示当前可用正文条数，提供“直接分析已有资料”与“导入链接或补充正文”；零正文时说明自动检索可能无结果。部分成果状态标题明确“采集已结束”，不表现为等待运行。新建已有资料分析允许无旧轮及 partial/stale 单角色旧轮，保留范围、真实资料、未排除/40字符、无活动任务/租约和业务空间保护检查。旧轮可用时原样存历史，无旧轮不写入空历史。

新轮仍最多2次请求，点击显式操作前不执行，无自动搜索/模型重试，不重置任何历史次数。没有扩大自动采集可达性或保证所有题目都有公开原文。

默认完整离线API回归通过：新增 partial/stale/新项目三场景均零 provider HTTP、保留累计用量和历史，进入 analyze 而非 plan/collect。生产构建含类型检查通过。实际项目的资料是否在同一项目中仍需用户核对顶部正文数量。
